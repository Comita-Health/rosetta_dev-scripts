# SPEC-BUG-decompose-grounding-P1: decompose synthesizes specs against an ungrounded prompt — phase boundaries are discarded and envelopes are invented, so every generated spec over-scopes Phase 1 and fails the envelope gate by construction

## Context

**Symptom:** All five specs generated by `decompose` on 2026-08-04 (PRD-0020 through PRD-0024) required manual correction before they were usable: four of five collapsed the PRD's Phase 2/3 work into "Phase 1" (13 tasks instead of 5 for PRD-0021), and all five emitted envelopes with hallucinated `allowedPaths` (`packages/daemon/**`, `src/engine/state/**` — directories that do not exist) and `forbiddenSurfaces` labels (`auth`, `billing`, `migrations`) that are not defined in the target repo's `.sdlc/surfaces.json`. Because the envelope gate treats an unresolvable surface label as a breach, every task diff of every generated spec would have red-gated regardless of content.

**Repro:** `bun run src/index.ts decompose --prd PRD-0021 --phase 1 --repo <rosetta_dev-scripts> --docs-dir <rosetta_docs>/product` — inspect the generated `specs/PRD-0021/phase-1-spec.md`: tasks cover the PRD's Phase 2 (verdict invalidation) and Phase 3 (circuit breakers, Chronicle recovery records), and the envelope references nonexistent paths and undefined surface labels.

**Root cause:** Two ungrounded prompts. (1) `SpecSynthesisService.buildPrompt` receives only the stories JSON and `options.phaseTitle` — the PRD parser already extracts every rollout phase's full `description` (`ParsedPrd.rolloutPhases`), but the synthesis prompt discards it, and never tells the model what the *other* phases own, so scope leaks in. Stories themselves are decomposed from the whole PRD with no phase awareness. (2) The prompt gives the model zero repository context — no directory layout, no `.sdlc/surfaces.json` labels — and its inline example even suggests `"migrations", "auth", "ci-config"` as `forbiddenSurfaces`, teaching the model to emit labels that don't exist in the target repo. Nothing validates the generated envelope before the spec is written.

**Why now / blast radius:** Every future PRD decompose inherits these defects; the manual calibration pass costs roughly an hour per batch and is exactly the kind of silent-quality failure the SDLC machine exists to remove. The fix touches the engine's planning path (`sdlc-workflow/src/**`), which overlaps `SPEC-BUG-envelope-spec-integrity-P1` (W5, in flight at authoring time) — this run must not fork until W5 lands, and the envelope validation in T-02 should reuse the spec-validation surface W5 lands rather than duplicating it.

## Task T-02: Ground and validate generated envelopes against the target repo

- **Story:** S-01
- **Complexity:** S
- **Depends on:** [T-01]
